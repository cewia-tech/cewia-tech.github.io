Política de Privacidad

Aplicación: Drive Painel - Multimídia

Última actualización: Agosto de 2026

Esta Política de Privacidad explica cómo Drive Painel - Multimídia accede y utiliza determinada información necesaria para su funcionamiento. Nuestro compromiso es ofrecer una aplicación sencilla, segura y transparente.

1. Datos personales

La aplicación no requiere crear una cuenta, iniciar sesión ni autenticarse y no solicita nombre, correo electrónico, teléfono, documentos, fotos, contactos u otra información de identificación personal.

CEWIA Tech no vende, alquila ni comparte los datos personales de los usuarios.

2. Ubicación

La aplicación utiliza la ubicación del dispositivo para calcular y mostrar funciones del panel, como:

  • Velocidad actual
  • Distancia recorrida
  • Velocidad máxima
  • Altitud
  • Tiempo en movimiento y tiempo detenido
  • Información relacionada con el trayecto

Estos datos se procesan localmente en el dispositivo. La aplicación no envía coordenadas de ubicación a los servidores de CEWIA Tech, no crea un historial de rutas y no comparte la ubicación con terceros.

El acceso a la ubicación se utiliza únicamente mientras las funciones del panel están activas y el usuario puede desactivarlo en la configuración de Android.

3. Sensores e información del dispositivo

La aplicación puede acceder a sensores e información técnica del dispositivo, como brújula, orientación, nivel de batería y estado de carga, exclusivamente para mostrar los instrumentos del panel.

Esta información se procesa localmente y no se transmite a CEWIA Tech.

4. Aplicaciones instaladas y accesos directos

Para permitir que el usuario elija aplicaciones rápidas y las abra en modo de pantalla dividida, Drive Painel - Multimídia puede acceder a información básica de aplicaciones compatibles instaladas en el dispositivo, como nombre, icono e identificador del paquete.

Esta información se utiliza únicamente para crear los accesos directos seleccionados por el usuario y no se envía a los servidores de CEWIA Tech.

5. Superposición y pantalla dividida

La aplicación puede solicitar permiso de superposición para mostrar un botón flotante que facilita el regreso a Drive Painel y el uso de la pantalla dividida. Este permiso no se utiliza para leer el contenido de otras aplicaciones, capturar la pantalla ni recopilar información personal.

6. Almacenamiento local

Preferencias como idioma, unidad de velocidad, estilo del velocímetro, escala máxima, aplicaciones rápidas y datos del trayecto pueden almacenarse localmente en el dispositivo.

Estos datos permanecen en el dispositivo y pueden eliminarse al borrar los datos de la aplicación o desinstalarla.

7. Uso de Internet

Las funciones principales de Drive Painel - Multimídia no dependen de servidores de CEWIA Tech. La aplicación no utiliza Internet para enviar datos personales, datos de ubicación o información del trayecto.

Las aplicaciones de terceros abiertas por el usuario, como Waze, Google Maps, Spotify u otras, pueden utilizar Internet y tratar datos de acuerdo con sus propias políticas de privacidad. CEWIA Tech no controla el funcionamiento de esas aplicaciones.

8. Publicidad, análisis y terceros

La aplicación no muestra anuncios, no utiliza herramientas de análisis de comportamiento y no vende información de los usuarios.

9. Seguridad

Como los datos utilizados por el panel se procesan localmente y no se almacenan en servidores de CEWIA Tech, se reduce la exposición de la información del usuario.

10. Menores

La aplicación no está dirigida específicamente a menores. No recopila conscientemente datos personales de menores ni presenta contenido inadecuado.

11. Cambios en esta Política

Esta Política podrá actualizarse si se añaden nuevas funciones o si se producen cambios legales u operativos. Siempre que esto ocurra, la fecha de actualización se revisará en esta página.
