Privacy Policy

Application: Drive Painel - Multimídia

Last updated: August 2026

This Privacy Policy explains how Drive Painel - Multimídia accesses and uses certain information required for its operation. Our commitment is to provide a simple, secure and transparent application.

1. Personal data

The application does not require account creation, login or authentication and does not request the user's name, email address, phone number, documents, photos, contacts or other personally identifying information.

CEWIA Tech does not sell, rent or share users' personal data.

2. Location

The application uses the device's location to calculate and display dashboard features such as:

  • Current speed
  • Distance traveled
  • Maximum speed
  • Altitude
  • Moving time and stopped time
  • Related trip information

This data is processed locally on the device. The application does not send location coordinates to CEWIA Tech servers, does not create a route history and does not share location data with third parties.

Location access is used only while the dashboard features are active and can be disabled by the user in the Android settings.

3. Sensors and device information

The application may access device sensors and technical information, such as the compass, orientation, battery level and charging status, solely to display the dashboard instruments.

This information is processed locally and is not transmitted to CEWIA Tech.

4. Installed applications and shortcuts

To allow the user to choose quick applications and open them in split-screen mode, Drive Painel - Multimídia may access basic information about compatible applications installed on the device, such as their name, icon and package identifier.

This information is used only to create the shortcuts selected by the user and is not sent to CEWIA Tech servers.

5. Overlay and split screen

The application may request overlay permission to display a floating button that makes it easier to return to Drive Painel and use split-screen mode. This permission is not used to read the content of other applications, capture the screen or collect personal information.

6. Local storage

Preferences such as language, speed unit, speedometer style, maximum scale, quick applications and trip data may be stored locally on the device.

This data remains on the device and can be removed by clearing the application's data or uninstalling it.

7. Internet use

The core features of Drive Painel - Multimídia do not depend on CEWIA Tech servers. The application does not use the internet to send personal data, location data or trip information.

Third-party applications opened by the user, such as Waze, Google Maps, Spotify or others, may use the internet and process data according to their own privacy policies. CEWIA Tech does not control the operation of those applications.

8. Advertising, analytics and third parties

The application does not display advertisements, does not use behavioral analytics tools and does not sell user information.

9. Security

Because the data used by the dashboard is processed locally and is not stored on CEWIA Tech servers, the exposure of user information is reduced.

10. Children

The application is not specifically directed to children. It does not knowingly collect personal data from children and does not contain inappropriate content.

11. Changes to this Policy

This Policy may be updated if new features are added or if legal and operational changes occur. Whenever this happens, the update date will be revised on this page.
