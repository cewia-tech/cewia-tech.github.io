Política de Privacidad

Nivel Profesional

Última actualización: 18 de septiembre de 2026

Nivel Profesional fue desarrollado para funcionar localmente en el dispositivo del usuario. CEWIA Tech no exige la creación de una cuenta, no muestra anuncios y no recopila ni envía las mediciones realizadas por el usuario a servidores de CEWIA Tech.

1. Sobre esta política

Esta Política de Privacidad explica cómo Nivel Profesional, desarrollado por CEWIA Tech, utiliza recursos del dispositivo para realizar mediciones de nivel, inclinación, superficie y ángulo.

2. Sensores del dispositivo

Para realizar las mediciones, Nivel Profesional utiliza sensores de movimiento y orientación disponibles en el dispositivo, como el acelerómetro, sensor de gravedad, giroscopio y/o sensor de rotación, según la disponibilidad y las características del dispositivo.

Las lecturas de los sensores se procesan localmente para calcular y mostrar las mediciones. CEWIA Tech no recibe las lecturas de los sensores ni las mediciones realizadas por el usuario. La disponibilidad y la precisión de los sensores pueden variar según el dispositivo.

3. Información recopilada

Nivel Profesional no exige registro ni inicio de sesión en CEWIA Tech y no fue desarrollado para recopilar datos personales del usuario. La aplicación no recopila el nombre, dirección, correo electrónico, número de teléfono o ubicación del usuario mediante servicios de CEWIA Tech.

4. Permisos y recursos no utilizados

La versión actual de Nivel Profesional no necesita acceso a la ubicación, cámara, micrófono o contactos para realizar sus funciones principales y no requiere conexión a Internet para realizar las mediciones.

5. Configuración y calibración

Las preferencias de la aplicación, la configuración y la información necesaria para la calibración pueden almacenarse localmente en el dispositivo para conservar las elecciones del usuario y permitir el funcionamiento adecuado de las funciones.

CEWIA Tech no utiliza esta información local para crear perfiles de usuario, publicidad o seguimiento.

6. Procesamiento y almacenamiento

Las funciones principales de Nivel Profesional se ejecutan localmente en el dispositivo. La aplicación no utiliza una cuenta propia de CEWIA Tech ni un servicio en la nube de CEWIA para almacenar las mediciones realizadas.

7. Intercambio y venta de datos

CEWIA Tech no vende los datos personales de los usuarios. Nivel Profesional no fue desarrollado para compartir mediciones o información personal con anunciantes, redes publicitarias o intermediarios de datos.

8. Publicidad y análisis de uso

La versión actual de Nivel Profesional no muestra anuncios y no utiliza herramientas de CEWIA Tech para crear perfiles publicitarios ni realizar un seguimiento individual del uso de la aplicación.

9. Seguridad

CEWIA Tech procura limitar la aplicación a los recursos necesarios para su funcionamiento y prioriza el procesamiento local. Sin embargo, ningún sistema puede garantizar una seguridad absoluta.

10. Niños

Nivel Profesional no está dirigido específicamente a niños y no incluye funciones destinadas a la recopilación intencional de datos personales de niños por parte de CEWIA Tech.

11. Cambios en esta política

Esta Política de Privacidad podrá actualizarse para reflejar cambios en la aplicación, requisitos legales o políticas de las plataformas utilizadas. La fecha de la última actualización se indicará al comienzo de esta página.
